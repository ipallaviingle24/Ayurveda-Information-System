## Assignment Details

### Assignment 1: Music Player Playlist
Implement a music playlist using a singly linked list.

**Functionalities:**
- Add songs
- Remove songs
- Display the playlist
- Play a specific song

### Assignment 2: Text Editor
Implement a simple text editor using a doubly linked list.

**Functionalities:**
- Insert text
- Delete text
- Display text
- Search text
- Print text in reverse

### Assignment 3: Browser History Management
Implement browser history using a stack.

**Functionalities:**
- Add a visited page
- Navigate back
- View the current page
- Check whether history is empty

### Assignment 4: Expression Conversion and Evaluation
Implement the following operations using stacks:
- Convert infix expressions to postfix
- Convert infix expressions to prefix
- Evaluate postfix expressions
- Evaluate prefix expressions

### Assignment 5: Restaurant Waitlist System
Implement a restaurant waitlist using a queue.

**Functionalities:**
- Add a party to the waitlist
- Seat a party
- Display the waitlist

### Assignment 6: Supermarket Checkout System
Implement a supermarket checkout system using a circular queue.

**Functionalities:**
- Customer arrival
- Customer checkout
- Close checkout counter
- View the customer at the front

### Assignment 7: Dictionary Implementation
Implement a dictionary using a binary search tree (BST), where each node stores a key-value pair.

**Functionalities:**
- Insert a word and handle duplicate entries
- Delete a word
- Search for a word
- Display the dictionary using tree traversal
- Display the mirror image of the dictionary
- Create a copy of the dictionary
- Display the dictionary level-wise

### Assignment 8: Library Book Index System
Implement a library book index using a threaded binary search tree (TBT), where each node stores a Book ID and Book Title.

**Objective:**
Support efficient inorder traversal without recursion or an auxiliary stack.

### Assignment 9: Maze Pathfinding
Find a path from the starting point to the goal in a maze represented as a grid using DFS and BFS.

**Status:** Pending

### Assignment 10: College Campus Graph
Represent the college campus using an adjacency list or adjacency matrix, with departments as vertices and distances as edge weights.

**Objective:**
Find a minimum spanning tree using Prim's or Kruskal's algorithm.

**Status:** Pending

### Assignment 11: Supply Chain Route Optimization
Model a supply chain network connecting suppliers, warehouses, distribution centers, and retail stores.

**Objective:**
Find the shortest route using Dijkstra's algorithm.

**Status:** Pending
